# Steamforge — пакет карточки RuStore

Актуализировано: 31.08.2026.

## Название

**Steamforge**

Запасной ASO-вариант, если понадобится более описательное название:

**Steamforge — стимпанк 2048**

Не менять название перед первой публикацией без необходимости: оно должно совпадать с брендингом внутри игры.

## Краткое описание

**Стимпанк-головоломка 2048 с мастерской, прогрессией и Overdrive**

Ограничение RuStore: до 80 символов.

## Полное описание

Steamforge — атмосферная головоломка на основе знакомой механики объединения плиток. Здесь вместо обычной таблицы чисел работает механическая мастерская: уголь превращается в шестерни, клапаны, поршни, котлы и всё более сложные механизмы, пока фабрика не доберётся до Механического ядра.

Объединяйте одинаковые детали, планируйте ходы и не позволяйте полю заполниться. Числовые значения остаются на плитках, поэтому правила легко читаются даже при первом запуске.

### Давление и Overdrive

Каждое удачное объединение повышает давление в системе. Заполните манометр до 100%, чтобы запустить Overdrive — короткий режим усиленной работы мастерской с удвоенными очками.

### Развитие мастерской

Завершённые партии дают опыт. Повышайте уровень мастерской, открывайте достижения и собирайте гемы. Гемы можно использовать для полезных инструментов, например дополнительной отмены хода или удаления слабой плитки.

### Ежедневные задания

Каждый день доступно отдельное испытание с воспроизводимыми условиями и наградой. Ежедневная награда и серия посещений дают дополнительную цель возвращаться в мастерскую.

### Достижения

В игре есть набор обычных и скрытых достижений: за новые уровни механизмов, Overdrive, ежедневные испытания, развитие мастерской и другие игровые события.

### Работает офлайн

Основной игровой процесс, прогресс, достижения и ежедневные задания не требуют постоянного подключения к интернету. Сеть используется сторонними сервисами аналитики и рекламы согласно выбранным настройкам приватности.

Steamforge рассчитан на короткие партии, но сохраняет текущую игру: можно закрыть приложение и продолжить позже с той же доски.

Особенности:

- поле 4×4 и понятная механика объединения;
- собственная стимпанк-визуальная система с латунью, медью и механическими приборами;
- Steam Pressure и режим Overdrive;
- уровни мастерской, гемы и достижения;
- ежедневное испытание и ежедневная награда;
- отмена хода и механический инструмент удаления плитки;
- автоматическое сохранение партии;
- полноценная офлайн-игра.

## Категория

Предпочтительно: **Игры → Головоломки**.

Если консоль предлагает другую актуальную иерархию категорий, выбирать ближайшую категорию головоломок/казуальных игр, не «Аркады».

## Возрастная категория

Предварительно: **0+**.

В текущей версии нет насилия, сексуального контента, брани, алкоголя/наркотиков или страшных сцен. Финальную категорию подтвердить по фактическому содержимому версии, загружаемой в RuStore.

## Скриншоты

Для каждого типа устройств, для которого загружаются скриншоты, RuStore требует минимум **3** изображения; консоль принимает до 10. Поддерживаемые пропорции — 9:16 для вертикальных и 16:9 для горизонтальных скриншотов. Для Steamforge рекомендуется 4–5 реальных вертикальных кадров.

Приоритет кадров:

1. **Gameplay** — поле с несколькими уровнями плиток, счёт и манометр давления.
2. **Workshop** — уровень мастерской, гемы, Daily Challenge и Daily Reward.
3. **Achievements** — часть открытых и закрытых достижений.
4. **CORE ONLINE / развитый gameplay** — если подготовлен реальный кадр из приложения.
5. **Settings** — только как дополнительный кадр, не ставить первым.

Не использовать concept-art вместо интерфейса. Скриншоты должны показывать фактический вид опубликованной сборки и не должны содержать элементы интерфейса Android/других приложений.

Текущий Actions workflow `UI Emulator Smoke` уже создаёт реальные кадры Workshop, Game, Achievements, Settings и compact-варианты. Для магазина использовать кадры стандартного телефона, перед загрузкой привести их к 9:16 без потери ключевого UI и проверить отсутствие debug/demo-индикаторов.

## Иконка

Подготовить отдельную store-иконку:

- 512×512 px;
- PNG или JPG;
- квадрат 1:1;
- фон заполняет всю площадь изображения;
- для совместимости с более строгой страницей требований держать файл ≤1 МБ.

Текущий launcher icon в Android-проекте остаётся векторным и не считается финальным store-artwork автоматически.

## Перед отправкой на модерацию

- использовать production credentials;
- собрать подписанный AAB/APK;
- проверить подпись;
- установить production build и пройти smoke-test;
- убедиться, что Privacy Policy открывается по production URL;
- проверить работу AppMetrica после consent;
- проверить production rewarded/interstitial;
- загрузить минимум 3 реальных скриншота одного типа/ориентации;
- проверить карточку на отсутствие плейсхолдеров и demo-данных;
- выбрать ручную публикацию после модерации для первого релиза, чтобы версия не вышла автоматически до финальной проверки.
