## Кратко

Steamforge не содержит рекламы и не использует AppMetrica или другой SDK пользовательской аналитики/телеметрии.

Приложение не требует регистрации и не запрашивает имя, телефон, e-mail, геолокацию, камеру, микрофон, контакты или содержимое пользовательских файлов.

## Данные на устройстве

Steamforge хранит игровой и служебный state локально через Android DataStore, включая, в зависимости от версии игры:

- игровой прогресс и статистику;
- гемы/ресурсы и прогрессию мастерской;
- достижения, контракты и коллекции;
- активную сохранённую партию и данные, необходимые для её детерминированного восстановления;
- настройки звука, вибрации и анимаций;
- кэш безопасной удалённой конфигурации, если production Remote Config endpoint включён.

«Настройки → Сбросить прогресс» удаляет игровой прогресс согласно текущей реализации, но может сохранять отдельные пользовательские настройки. Для удаления всех локальных данных Steamforge используйте системную функцию Android «Очистить данные/хранилище приложения» или удалите приложение.

## Системное резервное копирование Android

Приложение разрешает стандартные механизмы backup/data extraction Android в соответствии с `backup_rules` / `data_extraction_rules`. Поэтому часть локального состояния может попадать в резервное копирование или перенос средствами Android/поставщика системного backup, если такая функция включена пользователем.

Steamforge не управляет инфраструктурой системной резервной копии Android.

## Реклама и аналитика

Steamforge не содержит:

- Yandex Mobile Ads или другого рекламного SDK;
- rewarded/interstitial/banner/native рекламы;
- рекламных идентификаторов в собственной продуктовой логике;
- AppMetrica или другого пользовательского analytics SDK;
- отправки событий поведения/сессий в analytics service;
- consent-диалога для рекламы/аналитики;
- переключателя аналитики/рекламы в Settings.

Внутри исходного кода могут временно сохраняться типизированные event-call sites как архитектурный compatibility layer, но production implementation является локальным no-op: события не отправляются, не сохраняются и не образуют пользовательскую телеметрию.

## Сетевые функции

Базовый gameplay и локальное восстановление партии не требуют подключения к сети.

Приложение имеет разрешение `INTERNET`, поскольку архитектура поддерживает отдельные продуктовые сетевые функции, не являющиеся рекламой или аналитикой.

### Remote Config

Если владелец приложения задаёт production HTTPS Remote Config endpoint, Steamforge может периодически получать ограниченный конфигурационный JSON. Клиент использует HTTPS, ограничивает размер ответа и имеет compiled/local fallback, поэтому запуск и gameplay не зависят от сети.

Текущая Remote Config функция предназначена для получения конфигурации. Она не используется как канал пользовательской аналитики и не отправляет gameplay/event payload.

**Перед публикацией владелец должен указать здесь фактический домен production Remote Config, если endpoint включён:**

- Remote Config host: **[PLACEHOLDER или «не используется»]**

Как и при любом HTTPS-запросе, сетевой сервер/инфраструктура обычно технически получает сетевые данные соединения, например IP-адрес, необходимые для доставки запроса. Политику и сроки хранения серверных журналов необходимо описать по фактической production-инфраструктуре.

### Weekly ranking

В текущем клиентском baseline production Weekly ranking остаётся скрыт/недоступен, пока identity/backend deployment не завершены. Если эта функция будет включена в пользовательский релиз, политика должна быть обновлена **до включения** с точным описанием аккаунта/идентификации, replay submission, серверного хранения, сроков и удаления.

## Сторонние SDK

В текущем tracking-free baseline нет AppMetrica и рекламного SDK.

Android/Jetpack библиотеки используются для работы приложения, UI, lifecycle, navigation и локального хранения. Перед production release владелец должен повторно проверить dependency/manifest inventory итогового APK/AAB.

## Управление и удаление

1. Игровой прогресс — «Настройки → Сбросить прогресс».
2. Все локальные данные Steamforge — системная функция Android «Очистить данные/хранилище приложения» или удаление приложения.
3. Системные резервные копии — через настройки Android/аккаунта, предоставляющего backup.
4. По вопросам production server logs/Remote Config — обратиться по контакту владельца выше; фактическая процедура должна быть заполнена перед публикацией, если сервер используется.

## Что нужно заполнить перед публикацией

- имя/название владельца;
- контактный e-mail;
- дата публикации;
- используется ли production Remote Config;
- если используется — домен, оператор инфраструктуры, server-log retention/удаление;
- актуальные store/legal disclosure requirements;
- при будущем включении Weekly backend — отдельное обновление этой политики до player exposure.
