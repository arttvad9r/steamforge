# Steamforge 1.0 — заметки к первому релизу

Текст для поля «Что нового» / описания версии в RuStore, если оно запрашивается:

> Первый выпуск Steamforge. Стимпанк-головоломка на основе механики 2048: объединяйте детали, накапливайте давление и запускайте Overdrive. В версии 1.0 доступны развитие мастерской, гемы, достижения, ежедневное испытание и ежедневная награда, отмена хода, механический инструмент удаления плитки и сохранение партии для продолжения после перезапуска.

Короткий вариант:

> Первый выпуск Steamforge: 2048-механика, Steam Pressure и Overdrive, развитие мастерской, достижения, ежедневные задания и сохранение партии.

Перед публикацией не добавлять в release notes функции, которых нет в фактической production-сборке.
